OZD 변환과 조달청·DeepSeek 응답은 **테스트용 어댑터/응답 주입**이다. 실제 OZ 엔진의 바이너리 해석, 실제 API 인증 또는 운영 배포가 완료되었다는 뜻은 아니다. 테스트 실행기는 tests/fixtures/에만 있고 운영 코드가 참조하지 않는다.

## 브라우저 상호작용 검사

- 실제 dragenter/drop DataTransfer로 합성 XLSX 등록 → 원본 수량/단가/폐품 확인 → 번호 일치 조달 후보 → 빈칸 입력 → 상세 원본상태 확인.
- OZD 드래그 → 테스트 변환기 XLSX → 동일 미리보기.
- 미연결 OZD → 원본 대기/등록 차단 → 담당자 확인 후 수동 XLSX 연결 → 잘못된 파일 드롭 시 기존 결과 보존.
- 한국어 조합 중 Enter 미전송, Shift+Enter 줄바꿈, 일반 Enter 전송, Markdown 본문, 인용표식 비노출, 참고자료 기본접힘/펼치기/닫기.
- 390px 모바일 대화·파일 업로드 가로 넘침 없음. 기존 엑셀 사진/대량 상태/배송/권한/양 기관 전체 인계·대장 확인도 함께 통과.

Browser 커넥터는 현재 탭 읽기만 제공하여 실행환경의 Playwright Chromium을 사용했다. 데스크톱1440×1000, 모바일390×844에서 제목/본문/주요 버튼/상호작용을 확인했고 페이지 오류 수집 검사도 포함했다. 테스트 중 병렬 실행으로 QA 산출물 충돌이 한 번 있어, 이후에는 별도 포트에서 전체18개를 순차 재실행해 통과했다.
