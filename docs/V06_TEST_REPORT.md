신규 서버 검증: 목록번호 해석·번호 충돌·원본 보존, 실제 OOXML sheet/drawing/picture 관계 파싱, 외부/숨김/DTD 제외, 여러행 사진 자동확정 금지, 기관명 대조·부서별 묶음, 사진의 선택행/확인조건/멱등·다른물품 중복거부, 서버 캐시/동시조회/사용한도, JSON/XML·UTF8·인증오류 비노출, 서비스키 대소문자와 인코딩, HTTP 인증/CSRF/업무역할, 업로드이력/사진 기관격리, 참고사진이 게시용 현물 증거를 대체하지 않음, schema2→3 추가 마이그레이션과 원본 자산 보존.

신규 브라우저 흐름: XLSX 사진 후보 표시→직접 행 선택→비공개 초안 등록→현물/개인정보 확인→사진 연결→초안 품명·부서·사진 확인→부서 필터→업로드 이력. 모바일390px에서 카드·목록 전환, 재고·이력·등록 화면과 미설정 조달조회 버튼·가로 넘침 검사. 기존 전체 인계·RAG·배송 시나리오도 통과했다.

Browser connector는 탭 읽기만 지원하므로 실행환경의 Playwright를 사용했다. 캡처는 docs/screenshots/v06-* 및 CI 아티팩트에 있다. 자동화 DOM/폭 검사를 수행했으며 별도 이미지뷰어 육안 검수는 완료하지 못했다. 로컬/NAS 최종 시각 검수는 Codex 인계에 포함했다.

공급자 테스트는 모의 응답 주입이다. 실제 조달청 서비스키 인증, 기관별 이용승인·실제 참고사진 접근, 실제 공급자 응답을 선택해 저장하는 브라우저 흐름은 실환경에서 확인해야 한다. mock을 운영 성공 응답으로 사용하는 코드 경로는 없다. 신규 등록의 조회 UI는 빌드 및 키 미설정 차단을 검증했고 키 활성화된 실제 UI 적용·일괄반영·중단은 Codex 실접속 검사에 남긴다.

테스트 통과는 전체 엑셀 변형 지원이나 기관 보안·법률 적합성 심사가 끝났다는 뜻이 아니다. 외부 키·기존 NAS·실제 DB는 이번 작업에서 변경하지 않았다.
