## 브라우저 검사

기존 검색·신청·새로고침 영속성·관리자 권한·모바일 화면과 두 기관 전체 인계/부분 인수/대장 확인, 한글 CSV·첨부 실패·HEIC 재시도 흐름을 유지합니다. 새로 다음을 검사했습니다.

1. 합성 관리전환 XLSX 업로드 → 3행 머리글 탐지 → 열 매핑 미리보기 → 비공개80개 초안 → 예외수량으로 양호50/사용감20/수리10 배분 → 저장 → 사진 품명·명판 용도 업로드 → AI 미연결 버튼 차단 → 새로고침 보존.
2. 390px 배송 화면에서 포장 치수/무게/80개/주소/24km 입력 → 자동 예상액 → 수량 변경에 따른 재계산 → 예상견적 저장 → 가로 넘침 없음.
3. 390px 신규 등록 화면의 엑셀·수동 폼과 전체 페이지 가로 넘침 없음.

기존 첨부 E2E는 새 사진 품명 입력칸/엑셀 업로드칸과 충돌하지 않도록 파일 input을 종류별로 명확히 선택했습니다. 저장 완료를 기다린 뒤 다음 편집을 시작하도록 검사를 보완했습니다. 검사 내용이나 인계 승인 조건을 제거하지 않았습니다.
