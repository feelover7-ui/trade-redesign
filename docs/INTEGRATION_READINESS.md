## 확인된 명세의 범위

조달청 공식 HTTPS 서비스 기준 경로는 `https://apis.data.go.kr/1230000/ao/ThngListInfoService02`이다. 품목 검색 operation은 `getThngPrdnmLocplcAccotListInfoInfoPrdlstSearch02`이며, `serviceKey`, `pageNo`, `numOfRows`가 필수다. `krnPrdctNm`, `prdctIdntNo`, `dtilPrdctClsfcNo` 등의 검색 필드를 제공한다. 제조사 검색은 별도 소재지별 operation의 `mnfctCorpNm`을 확인했다. **모델명 전용 필드를 추측해 추가하지 않는다.** 분류번호(8자리), 세부품명번호(10자리), 물품식별번호, 기관 내부 자산번호는 각각 구분한다.

온비드 공식 HTTPS 기준 경로는 `https://apis.data.go.kr/B010003/OnbidCltrBidRsltListSrvc2`, operation은 `getCltrBidRsltList2`이다. 필수 필드는 `serviceKey`, `pageNo`, `numOfRows`, `resultType`, `cltrTypeCd`, `prptDivCd`, `opbdDtStart`, `opbdDtEnd`다. 동산은 `cltrTypeCd=0003`, 불용품 재산유형은 `prptDivCd=0004`로 명시되어 있다. 종료일은 현재 이전 시점이어야 한다. 결과의 `cltrMngNo`와 `pbctCdtnNo`는 상세조회용 참조이며 사이트 내부 자산번호로 대체하지 않는다.

두 포털 상세 페이지는 무료·이용허락범위 제한 없음·개발/운영 자동승인·개발계정 트래픽 1,000으로 표시했다. **자동승인은 이미 승인받았다는 뜻이 아니다.** 유효한 활용신청과 서비스키가 여전히 필요하다. 조달청 데이터 이용범위를 링크된 모든 이미지의 독립적인 재배포 권한으로 확대하지 않는다. [온비드 Open API 이용약관](https://m.onbid.co.kr/op/btbdguid/etcguidpage/EtcGuidPageController/mvmnUtlzTrms.do)은 온비드로 오인시키는 재배포·입찰질서 침해·서비스 과부하 등에 이용 제한을 둘 수 있음을 확인했다. 실제 이용 전 운영기관이 적용 약관을 확인해야 한다.

## 연결 시 보존 조건

- 기관별 외부 ID, 출처, 조회 시각, 원문 해시, 외부 처리번호·멱등키를 수동 증빙과 분리해 보관한다. 저장 구조를 바꾸기 전 버전 마이그레이션과 복구 절차를 추가한다.
- 허가된 읽기부터 시작한다. 타임아웃·401/403·429·빈 결과·결정 취소·중복 충돌은 성공으로 표시하지 않는다.
- 참고사진은 현물사진·상태 증거와 별도로 저장·표시한다. 허용 도메인/DNS·IP 재검증·사설망 차단·리디렉션 제한·MIME/용량 제한·캐시가 구현되기 전 이미지를 서버에서 가져오지 않는다.
- AI 출력은 근거·신뢰 수준·미확인 경고가 있는 제안이다. 사람이 확인한 수량·원본 대장·승인 상태에 직접 쓰지 않는다. 승인된 공급자를 임의로 선택하거나 다른 앱의 자격증명을 복사하지 않는다.
- `.env`, DB, 업로드, 로그, 백업과 실기관 자료는 Git에 넣지 않는다. 이번 검수 CSV·사진·증빙은 모두 합성 자료다.

실제 기관 CSV는 제공되지 않았다. 따라서 UTF-8/CP949의 실제 파일 업로드·열 매핑·내보내기는 검증했지만 **K-에듀파인 실기관 출력/재업로드 호환성 검증 완료는 아니다.**
