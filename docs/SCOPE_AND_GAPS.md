# 3일 MVP 범위와 남은 작업

## v0.2 설계에서 보존한 핵심

사진 중심 기관 간 검색, 불용결정 완료 검증 전 비공개, 원본 대장/실제 물품 분리, 묶음·상태 수량, 다른 검토자 승인, 예비 배정, 양측 증빙·실물·대장 확인, 초과 예약 방지, 기관별 파일 접근, 감사 이력을 구현했다.

18주 정식 운영 로드맵을 3일에 모두 완료했다고 주장하지 않는다. 이 저장소는 **외부 연결 없이 기능 시연·업무 검토를 할 수 있는 수동 모드 제품**이다.

## 이번 구현의 구체적인 제한

| 항목 | 현재 범위 | 후속 작업 |
|---|---|---|
| 인증 | 로컬 세션·기관별 역할·관리자 발급 | 공식 소속 확인 경로, SSO, MFA, 로그인 정책 |
| 불용결정 | 첨부 증빙 + 다른 기관 내 검토자 확인 | 인가된 공식 상태 조회·취소 재조회 |
| 법령 | 단계 안내 및 v0.2 근거 표시, 금액/기한 자동판정 없음 | 현행 지침 검증, 기관·회계·시행일 정책엔진 |
| 대장 입력 | CSV 열 매핑/원본 보존, 수동 입력 | 실제 에듀파인 출력 XLSX 파서와 인증된 재업로드 형식 |
| 묶음 | 같은 결정에 대한 하나의 묶음, 원본 자산행 하나는 한 묶음에 연결 | 서로 다른 회계·결정번호의 정밀 검증, 원장 행의 여러 묶음 분할 |
| 개체 | 원본 자산행과 수량을 거래에 연결 | 일련번호/RFID/QR별 Unit 테이블 및 스캔 |
| 인계 | 한 신청당 한 번 인계, 수량별 별도 신청으로 분할 가능 | 여러 차례 부분 인계·서명·일정 캘린더 |
| 수량 불일치 | 계속 보류, 실제 전량 수령을 확인하면 정상 인수로 전환 | 반송·분실·재처분·부분 종결 및 양 기관 승인에 따른 재고 복원 |
| 신청 이력 이후 편집 | 원본 보존을 위해 내용/그룹 수정 차단 | 버전별 변경 검토·영향 분석·정정 사건 |
| 파일 | 이미지 재인코딩/EXIF 제거·크기 제한·ACL·PDF 다운로드 | 기관 승인 백신/CDR, 자동 마스킹, 보존·파기정책, 암호화 저장 |
| 검색 | 일반 단어/모델/기관·필터·관심물품 | 동의어·오타·자연어·추천·알림 |
| 서식 | CSV, Markdown 초안, 브라우저 인쇄 | 공식 HWP/XLSX/PDF 양식 검증 |
| 온비드 | 매각 검토 ZIP, 중복 배정 방지 | 공식 조회 API, 기관용 쓰기 명세가 있는 경우만 전송 |
| 외부 API·AI | 연결하지 않음. capability=false, 어댑터는 명시적으로 오류 반환 | 승인·키·규격 확보 후 구현 |
| 호스팅 | 단일 Node + 로컬 SQLite/파일 | 승인된 인프라, PostgreSQL, 객체저장소, 백업·복구·보안심사 |
| 운영 | 수동 계정·최근 감사 100건·로컬 백업 | 보존 정책, 장애 모니터링, 감사 검색·반출, 기관 중지 영향검토 |

## 3일 사용 계획(작업 분배 제안, 향후 수행 약속이 아님)

- **1일차:** 저장소 설치·빌드·테스트. 담당자/검토자 계정으로 등록·게시·받기 신청 시연. 합성 사진·증빙만 사용.
- **2일차:** 실제 업무담당자에게 상태별 수량과 증빙 단계 검토. 비식별화한 실제 CSV 열 이름으로 매핑 검증. 시연에서 막히는 UI 수정.
- **3일차:** 두 기관 전체 인계 흐름·모바일 재검수. 승인된 시연환경 구성, 백업복원 확인, 시연영상 준비. 외부 API·AI는 확보된 범위만 연결.

## 정식 운영 전 보안·행정 승인

현재 로컬 로그인과 수동 기관등록을 공식 소속 인증으로 주장하지 않는다. 법령상 소요조회 대상 범위·기한·예외를 로그인 기관 범위로 대체하지 않는다. 민감 자료를 외부 AI나 개인 서버로 전송하지 않는다. 외부 노출 전 HTTPS, 접근권한·세션·망연계, 백신/CDR, 데이터 보호·보관기한, 개인정보 처리, 이용 승인, 백업·복구 및 실제 사용자 수용검수가 필요하다.
