### 브라우저에서 끝까지 확인한 업무

합성 신규 물품 3개 등록 → 한글 현물사진·증빙 첨부 → 작성자와 다른 검토자 6항목 확인 → 게시 → 다른 기관 신청 → 예비 배정 → 양 기관 검토자 증빙 → 실제 UTF-8 CSV 파일 업로드·열 매핑·자산 연결 → 인계 → 2개 인수로 불일치/보류 → 3개 전량 확인 → 양측 대장 근거 → 모든 수동 증빙 확인 완료까지 진행했다. 완료 화면에서 공식 API로 검증한 행정완료가 아니라는 안내도 확인했다.

CSV 다운로드의 UTF-8 BOM·한글 파일명·`00001234` 자산번호·`00123456` 분류번호·`00005678` 식별번호를 실제 바이트로 검사했다. 별도 CP949 CSV 파일도 업로드·저장했다. 온비드 ZIP의 사진·JSON·CSV를 실제로 내려받아 확인하고, 예약 뒤 ZIP 생성을 차단하는 오류 안내도 확인했다. 한글 증빙 다운로드 헤더와 MIME을 검사했다.

### 수정한 결함과 실패 경로

- 여러 파일 중 일부 실패 시 이미 저장된 파일을 갱신하고 저장 개수·남은 파일 재시도를 안내한다. 같은 HEIC 파일 재선택과 JPEG 변환 안내를 검사했다.
- 중복 CSV 열을 Papa Parse가 자동 이름 변경하여 통과시키던 경로를 차단했다. 새 파일 선택 시 이전 미리보기를 비우고 동일 파일 재선택을 허용한다. 가져오기 결과는 화면 알림으로 표시한다.
- 다른 담당자가 먼저 저장한 실제 버전 충돌을 발생시켜 실패 메시지, 새로고침 후 최신 내용, 정상 재저장을 확인했다. 선행 증빙 없는 인계도 성공으로 표시하지 않는다.
- E2E의 기존 서버 재사용을 없애고 4311과 실행별 새 합성 DB로 격리했다. 시연 4310의 DB는 테스트가 수정하지 않는다.
- production demo 실행의 환경변수 강제 변경 우회를 차단했다. 백업이 잘못된 원본 경로에 빈 DB를 만들던 동작을 없앴다. 해시·누락 첨부·복원 대상 중복 검사를 추가했다.

### 저장경로와 보존

최초 Documents 작업폴더는 빈 Git 저장소였으며 DB·업로드·인증 설정·해당 포트 서비스가 없었다. main을 받은 뒤 Documents 파일이 `dataless`가 되어 테스트/빌드가 파일 읽기 오류로 중단됐다. 원본을 삭제하지 않고 `~/Developer/trade` 사본에서 설치부터 다시 검수했다. 브라우저 다운로드는 디스크 부족으로 실패해 설치된 Chrome을 사용했다.

최초 시연 데이터 `data/demo/`와 모든 E2E 경로는 보존했다. 최종 검수 원본은 `data/e2e-TbThw7/`, 백업은 `backups/2026-10-31T05-06-55.006Z/`, 실제 재기동한 시연 DATA_DIR은 `data/restored-2026-10-31T05-06-55.024Z/`이다. DB 스키마는 user_version=1을 유지했다. 이 파일들은 Git에서 제외된다. 검수 서버는 중지했고 4310의 합성 시연 서버만 유지했다.

### 현재 검증 한계

승인된 배포 대상·영속 인프라·실제 HTTPS 종단이 없어 원격 배포는 하지 않았다. Docker가 설치되어 있지 않아 컨테이너 실행은 미검증이다. 실기관 CSV·인증·기관망·공식 행정 처리·외부 API/AI 호출도 미검증이며 [명세 확인 기록](INTEGRATION_READINESS.md)에 남겼다. Mac 디스크 여유 부족은 지속 운영 전에 해소해야 한다. 본 결과는 기관 운영·보안 승인을 대신하지 않는다.

## 발견하여 수정한 항목

작성자뿐 아니라 본문·첨부를 수정한 담당자도 해당 물품의 독립 검토 승인을 할 수 없도록 보강했습니다. 클라이언트가 원본 대장 필드를 변조해 전송해도 최초 원본이 유지됩니다. 이미지 처리 중 검토 단계가 바뀌는 경우를 서버 트랜잭션에서 다시 검사합니다. 한글 파일명 인코딩과 제어문자를 처리했습니다.

의존성 검사에서 이미지 처리 라이브러리의 보안 경고를 발견하여 **Sharp 0.35.5로 고정하고 잠금 파일을 갱신**했습니다. 이후 실제 사진 업로드·재인코딩 테스트, 전체 빌드, 브라우저 테스트 및 의존성 보안검사를 다시 통과했습니다. 보안검사는 해당 시점의 알려진 의존성 경고 확인이며 프로그램 전체의 보안 인증을 뜻하지 않습니다.

## 검증되지 않은 범위

- 사용자 Mac/Windows의 실제 로컬 환경, 기관 업무망, Docker 실행, 실제 도메인 배포는 아직 검증하지 않았습니다.
- 자동 생성한 화면 캡처를 저장소에 보관했으나, 별도 사람이 모든 화면을 육안으로 검수한 결과물은 아닙니다. Codex 인계에 실제 브라우저 시각 검수를 포함했습니다.
- 공식 K-에듀파인·조달청·온비드 연결, AI 호출, 실제 기관 인증, 법정 업무 적합성은 이번 테스트 범위에 없습니다.
- 본 검증은 정식 보안심사, 부하시험, 개인정보 영향평가, 기관 운영 승인을 대신하지 않습니다.
