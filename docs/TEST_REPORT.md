## 발견하여 수정한 항목

작성자뿐 아니라 본문·첨부를 수정한 담당자도 해당 물품의 독립 검토 승인을 할 수 없도록 보강했습니다. 클라이언트가 원본 대장 필드를 변조해 전송해도 최초 원본이 유지됩니다. 이미지 처리 중 검토 단계가 바뀌는 경우를 서버 트랜잭션에서 다시 검사합니다. 한글 파일명 인코딩과 제어문자를 처리했습니다.

의존성 검사에서 이미지 처리 라이브러리의 보안 경고를 발견하여 **Sharp 0.35.5로 고정하고 잠금 파일을 갱신**했습니다. 이후 실제 사진 업로드·재인코딩 테스트, 전체 빌드, 브라우저 테스트 및 의존성 보안검사를 다시 통과했습니다. 보안검사는 해당 시점의 알려진 의존성 경고 확인이며 프로그램 전체의 보안 인증을 뜻하지 않습니다.

## 검증되지 않은 범위

- 사용자 Mac/Windows의 실제 로컬 환경, 기관 업무망, Docker 실행, 실제 도메인 배포는 아직 검증하지 않았습니다.
- 자동 생성한 화면 캡처를 저장소에 보관했으나, 별도 사람이 모든 화면을 육안으로 검수한 결과물은 아닙니다. Codex 인계에 실제 브라우저 시각 검수를 포함했습니다.
- 공식 K-에듀파인·조달청·온비드 연결, AI 호출, 실제 기관 인증, 법정 업무 적합성은 이번 테스트 범위에 없습니다.
- 본 검증은 정식 보안심사, 부하시험, 개인정보 영향평가, 기관 운영 승인을 대신하지 않습니다.

## 결과물 위치

`docs/screenshots/`에는 자동 브라우저 테스트가 실제로 실행한 합성 시연 화면이 있습니다. 각 Actions 실행의 Artifacts에는 테스트 보고서와 실패 시 추적 정보가 저장됩니다. 정상 CI 성공 시 `trade-mvp-source-and-build`에는 소스와 빌드된 프런트엔드를 함께 넣습니다.
