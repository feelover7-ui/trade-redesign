# v0.7 파일 등록 통합·대화형 AI 화면

기준 main: `8e249ed6b50285f733fe19c195358992e7ef76b6`. 작업일 2026-11-04.

## 사용자 흐름

물품 올리기 → 엑셀/XLS/OZD 드래그 또는 선택 → 같은 표 미리보기·열 연결 → 원본 상태·수량·취득정보 확인 → 비공개 초안 → 조달청 후보 조회 → 선택한 빈칸 입력 → 현물·증빙 검토 후 공개. 파일 업로드 자체로 공개하거나 승인하지 않는다.

‘등록 후 조달청 제품정보 바로 조회’는 조회만 수행한다. ‘번호가 정확히 일치한 후보의 빈칸도 입력하기’는 별도 선택이며 기본 미선택이다. 서버가 정확번호 후보·빈칸·동일 버전을 검증한다. 기존 값·품명·수량·원본 번호·취득단가·폐품 상태는 덮어쓰지 않는다. 품명 후보는 담당자가 직접 고른다. 50묶음씩 페이지 이동해 처리하며 API 실패 시 등록 초안은 유지된다.

## Excel / OZD 차이와 한계

XLSX/XLS 파싱은 기존 모듈을 사용한다. `G2B목록번호` 별칭 누락을 수정하고 `등록수량`, `취득단가` 등 소요조회 항목을 추가했다. 명시적으로 쉼표로 구분한 G2B목록명에서만 품명·제조사·모델·규격을 분리한다. 정보가 모호하면 추정하지 않는다. 날짜 셀/원본 행·각기 다른 단가는 보존한다. 원본에 ‘폐품’이라고 적혀 있어도 실제 상태그룹은 UNKNOWN으로 시작한다.

OZD는 `OZP` 계열 원본 식별 후 승인된 별도 변환기로 XLSX를 받아 동일 파서로 검증한다. **OZD 전용 변환 엔진은 포함되지 않았다.** 실제 엔진·라이선스·어댑터 연결과 사용자 OZD 실변환은 Codex에서 마무리해야 한다. 변환기가 없거나 실패하면 원본만 보관하고 WAITING, 물품은 0건 생성한다. 같은 OZD를 OZ Viewer에서 XLSX로 내보낸 파일을 담당자가 확인해 연결하는 대체 경로도 제공한다. 임의 OZD 내부텍스트 추출이나 AI 추측을 성공 변환으로 처리하지 않는다.

관련 코드: `server/document-import.mjs`, `server/ozd-converter.mjs`, `tools/ozd-bridge/`. 브릿지 계약은 물품이음 내부 구현으로 공급자의 공식 API와 다르다.

## 공개 상세페이지

제조사·모델·규격·목록번호와 함께 원본 수량/취득일/취득단가/원본 상태를 보여준다. 과거 원본값은 현재 물품 상태·가격·인계 가능 수량과 구분한다. 전체 원본 파일·파일명·자산번호·결재정보는 타 기관에 공개하지 않는다. 원본에 폐품/폐기가 있으면 확인 문구를 보여준다. 기존 현물/참고사진 구분을 유지한다.

## 대화창

사용자 말풍선, AI 본문, 하단 입력창, Markdown 굵은 글씨·목록·표, Enter 전송/Shift+Enter 줄바꿈, 한국어 조합 중 Enter 방어, 응답 대기, 복사, 새 대화. API 연결·전송 동의가 없으면 ‘자료 검색 모드’라고 표시한다. 생성 성공을 가장하지 않는다.

본문에 `[S1] 출처 보기` 등은 표시하지 않는다. 출처는 답변당 `참고자료 N` 버튼 하나로 접혀 있고 사용자가 눌러야 카드·구절·파일·기능 이동이 보인다. 서버의 출처ID 검증·권한·원문 링크는 제거하지 않았다. 모델이 만들어낸 HTML, 외부 이미지, 임의 링크는 실행/로드하지 않는다. 질문·응답 본문은 기존과 같이 화면 메모리에만 보관한다.

## 데이터와 운영

schema v4에 `import_documents` 테이블만 추가해 원본 bytes/hash, 변환 hash/name/method를 저장한다. 기존 schema2/3에서 추가 이행하며 기존 업무 테이블·데이터는 유지한다. 원본을 DB에 넣으므로 기존 SQLite 백업에 포함되지만 용량 증가·보존/파기 기간은 기관 정책으로 운영해야 한다. v4 DB를 v3 코드로 직접 열지 않는다. 롤백은 이전 백업을 새 경로로 복원한다. RAG corpus·rag-usage.sqlite는 기존처럼 별도 백업한다.

외부 키는 서버에만 있다. 이 작업에서는 실제 API 키·운영 NAS·실제 업무 DB를 읽거나 변경하지 않았다. 사용자가 기존 Codex에 넣은 키를 재사용하고 누락 설정만 추가한다. 소요조회 XLSX/OZD 실파일은 이번 실행환경에서 직접 변환 재검수하지 못했으므로 합성 동일 헤더/상태 자료로 검증한 범위를 구분한다.
